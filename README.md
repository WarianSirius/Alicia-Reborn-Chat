# Alicia Voice Chat

Windows 11 voice-to-text helper for Alicia Reborn. Experimental: automatic chat input has not yet been validated in-game.

## Build
GitHub Actions > Windows Setup > Run workflow creates an installer artifact. A version tag such as `v1.2.0` also publishes the installer to GitHub Releases.

## For players
Download `AliciaVoiceChat_Setup.exe` from Releases once published. Python is not required on the player's computer.

## Updates
The app checks the latest GitHub release. Future releases require a new version number, a successful Windows build, and a published release. Do not publish an untested build as stable.
